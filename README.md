# CarbonLens AI — Interactive Streamlit Website

## Features
- Sustainability-themed responsive UI with a custom sidebar and hero banner
- Dashboard KPI cards and interactive trend chart
- Carbon estimator with breakdown chart and calculation details
- Digital Twin sliders and baseline/scenario comparison
- Rule-based sustainability recommendations
- SQLite simulation history, searchable records, charts, CSV export, and guarded deletion

## Run on Windows
1. Extract this ZIP.
2. Open a terminal in the extracted folder.
3. Install dependencies:
   `python -m pip install -r requirements.txt`
4. Run:
   `python -m streamlit run app.py`
5. Open the local URL printed in the terminal, usually http://localhost:8501.

Optional: place `logo.png` in the project folder to show your logo.

Note: emission factors and dashboard metrics are illustrative sample values. Recommendations are rule-based; a trained ML model is not included.
